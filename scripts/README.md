# Scripts

Operational and data scripts that support the platform but aren't part
of the frontend or backend applications.

- `ingest/` — per-source data ingestion scripts (none yet; see its own README).
- `research/` — small, non-production exploratory scripts used to
  investigate a source's API before building real ingestion (see its
  own README/module docstrings, e.g. `denver_arcgis_explore.py`).
